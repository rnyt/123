# 🎓 Бот «Мои оценки»

Telegram-бот, который считает средний балл, следит за обязательными контрольными (ОКР)
и защитой лабораторных/практических и сразу показывает, где ты **не аттестован**.
Раз в 1–3 дня напоминает внести новые оценки — но только если ты сам давно ничего не вносил.

```
🎓 Осень 2026
📊 Средний балл: 8,25 ≈ 8
📚 4 предмета · 5 оценок
🗓 За неделю: +5 оценок · средний ▲0,12
🔬 Защищено работ: 1 из 3 ▰▱▱

❌ Не аттестован: 3 из 4
📌 Нет ОКР: Высшая математика, Программирование
⏳ Не защищены: Физика (ЛР 2, ЛР 3)

💡 Пиши прямо в чат: «физ 8 9» — оценки сразу попадут в физику.
[📐 Высшая математика · — ❌]
[⚛️ Физика · 8,00 ❌]
[💻 Программирование · 8,50 ❌]
[🇬🇧 Английский язык · — ✅]
[➕ Предметы] [📊 Статистика]
[⚙️ Настройки] [❓ Помощь]
```

Карточка предмета:

```
⚛️ Физика

📊 Средний: 8,00 ≈ 8 · 3 оценки
📝 8, 9
📌 ОКР: 7 ✅
🔬 Лабораторные: 1 из 3 ▰▱▱
⏳ Не защищены: ЛР 2, ЛР 3
📈 До «9» не хватает: 1 × 10 или 3 × 9

❌ Не аттестован: не защищены ЛР 2, ЛР 3
[➕ Оценки] [📌 ОКР]
[🔬 + Лабораторная] [🛠 + Практическая]
[📂 Работы · защищено 1 из 3]
[✏️ Изменить оценки] [⚙️ Предмет]
[⬅️ Меню]
```

## Что умеет

- **Знакомство за 3 шага**: шкала (10- или 5-балльная), список предметов одним сообщением,
  в каких предметах есть ОКР.
- **Главное меню**: общий средний балл, динамика за неделю, у каждого предмета средний и
  статус ✅/❌, и сводка *почему* не аттестован: нет ОКР, ОКР ниже порога, не защищены работы.
- **Оценки**: кнопками в одно касание или сообщением сразу несколько — `8 9 10`, `8, 9`, `8/9`.
- **Быстрый ввод из любого места**: `физ 8 9`, `8 9` (бот спросит предмет), `физ окр 7`,
  `физ` (открыть предмет), а за весь день — одним сообщением: `физ 8 9, матан 7` или по строкам.
  Понимает сокращения и сленг: «матан», «вышка», «англ», «оаип», «физра», опечатки.
- **ОКР** — отдельной кнопкой. Порог сдачи настраивается (по умолчанию от 4 на 10-балльной
  и от 3 на 5-балльной). Если ОКР несколько — настраивается в предмете.
- **Лабораторные и практические**: добавление пачкой с автонумерацией (+1…+12) или по названиям,
  список «✅/⏳», карточка работы с кнопками «✅ Защитил» и «⬅️ Назад».
- **Аттестация**: нет оценки за ОКР, ОКР ниже порога или есть незащищённая работа — предмет ❌,
  и это видно в главном меню.
- **Цель**: «📈 До «9» не хватает: 1 × 10 или 3 × 9».
- **Отмена** любого добавления (↩️), правка и удаление оценок с возвратом.
- **Умные напоминания**: каждый день / раз в 2 дня / раз в 3 дня в выбранное время, по твоему
  часовому поясу, не в воскресенье (по желанию), «⏰ напомнить через 2 часа».
- **Чистый чат**: в чате живёт одно сообщение-меню, твои сообщения бот убирает (отключаемо).
- **Статистика**: распределение оценок, рейтинг предметов, прогресс по работам.
- **Семестры**: старый уходит в архив с итогами, предметы можно перенести в новый.
- **Экспорт в Excel** (CSV) — все оценки, ОКР и работы.
- **Личный режим**: можно разрешить бота только себе (`ALLOWED_USERS`).

## Запуск за 5 минут

1. Создай бота: в Telegram открой [@BotFather](https://t.me/BotFather) → `/newbot` → скопируй токен.
2. Нужен Python 3.11 или новее.
3. В папке `grades-bot`:

   ```bash
   python -m venv .venv
   source .venv/bin/activate          # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   cp .env.example .env               # Windows: copy .env.example .env
   ```

4. Открой `.env` и впиши токен: `BOT_TOKEN=1234567890:AAH...`
5. Запусти:

   ```bash
   python -m bot
   ```

6. Напиши своему боту `/start` в Telegram.

Бот работает, пока запущена программа. Чтобы он работал всегда, запусти его на сервере.

### Docker (на сервере, 24/7)

```bash
cp .env.example .env    # впиши BOT_TOKEN
docker compose up -d --build
docker compose logs -f  # посмотреть логи
```

База лежит в `./data/grades.db` — переживает перезапуски и обновления.

### systemd (Linux без Docker)

```ini
# /etc/systemd/system/grades-bot.service
[Unit]
Description=Grades Telegram bot
After=network-online.target

[Service]
WorkingDirectory=/opt/grades-bot
ExecStart=/opt/grades-bot/.venv/bin/python -m bot
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now grades-bot
```

## Настройки (`.env`)

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен от @BotFather (обязательно) | — |
| `DEFAULT_TZ` | Часовой пояс новых пользователей (в боте меняется) | `Europe/Minsk` |
| `ALLOWED_USERS` | Id через запятую — только им можно пользоваться ботом | пусто = всем |
| `DB_PATH` | Путь к базе SQLite | `data/grades.db` |
| `PROXY_URL` | Прокси до Telegram: `http://user:pass@host:port` | пусто |
| `LOG_LEVEL` | `DEBUG` / `INFO` / `WARNING` | `INFO` |

Свой Telegram id подскажет [@userinfobot](https://t.me/userinfobot).

**Резервная копия** — это файл `data/grades.db`. Скопируй его, и все данные с тобой.

## Как пользоваться

| Пишешь в чат | Что произойдёт |
|---|---|
| `физ 8 9` | оценки 8 и 9 в «Физику» |
| `Физика: 8, 9/10` | то же, разделители любые |
| `8 9` | бот спросит, в какой предмет |
| `физ окр 7` | оценка за ОКР |
| `физ` | открыть карточку предмета |
| `физ 8, матан 7` или по строкам | сразу в несколько предметов |
| `8 9` на карточке предмета | оценки в этот предмет |

Если название подходит к нескольким предметам («физ» — Физика и Физкультура), бот покажет кнопки.

**Аттестация.** Предмет ❌, если нет оценки за ОКР, ОКР ниже порога или не защищена хоть одна
лабораторная или практическая. В предметах без ОКР (например, физкультура) смотрятся только работы.

**Средний балл** предмета — по всем его оценкам вместе с ОКР. Общий — среднее по предметам:
у каждого предмета равный вес. Отдельно в статистике есть «по всем оценкам подряд».

**Напоминания.** Приходят в выбранное время (по умолчанию в 20:00, раз в 2 дня), только если за
этот срок ты ничего не вносил. Не беспокоят ночью и (по желанию) в воскресенье.

## Как бот улучшался: 20 шагов

1. **Каркас**: aiogram 3, настройки из `.env`, понятные сообщения, если токен не тот или нет связи.
2. **Надёжное хранилище**: SQLite с миграциями, WAL и внешними ключами. Состояние диалога тоже
   в базе — после перезапуска бот помнит, чего ждал от тебя.
3. **Знакомство за 3 шага**: шкала → предметы списком (дубли и мусор отсеиваются) → где есть ОКР.
4. **Главное меню-дашборд**: средний балл, статусы предметов и причины неаттестации, сгруппированные
   по типу (нет ОКР / ОКР ниже порога / не защищены).
5. **Карточка предмета**: оценки, ОКР, прогресс-бары по лабораторным и практическим.
6. **Ввод оценок в одно касание**: клавиатура 1–10 или 2–5 с живым пересчётом среднего,
   «убрать последнюю», пачкой текстом с любыми разделителями.
7. **ОКР**: отдельная кнопка, порог сдачи, несколько ОКР в предмете, «было → стало».
8. **Работы**: добавление пачкой с автонумерацией или по названиям; «📂 Работы» появляется после
   первой работы; карточка «✅ Защитил / ⬅️ Назад»; переименование и удаление.
9. **Правила аттестации** с объяснением *почему* — на карточке, в меню и в напоминании.
10. **Быстрый ввод текстом**: `физ 8 9`, `8 9`, `физ окр 7`; поиск по началу слова, аббревиатуре
    («оаип»), студенческому сленгу («матан», «вышка», «физра») и с опечатками.
11. **Отмена**: после любого добавления — «↩️ Отменить»; удалённую оценку можно вернуть.
12. **Цель**: сколько и каких оценок не хватает до следующего округлённого балла.
13. **Умные напоминания**: в своё время, раз в 1–3 дня, только если давно не вносил;
    с выжимкой проблем и «⏰ через 2 часа».
14. **Часовой пояс** (города или `+3`) и «не беспокоить в воскресенье».
15. **Чистый чат**: одна живая панель вместо ленты сообщений; сообщения пользователя убираются.
16. **Статистика**: распределение оценок, рейтинг предметов, динамика за неделю.
17. **Управление предметами**: переименование, своя иконка-эмодзи, порядок, удаление, число ОКР;
    иконки подбираются автоматически (📐 математика, ⚛️ физика, 💻 программирование…).
18. **Семестры**: архив с итогами и перенос списка предметов в новый семестр.
19. **Всё за день одним сообщением**: `физ 8 9, матан 7` или по строкам — с отчётом, что не понял.
20. **Надёжность и удобство**: экспорт в Excel; проверка, что данные свои; очередь нажатий без гонок;
    защита от лимитов Telegram; личный режим; Docker; 120+ автотестов на фейковом Telegram.
