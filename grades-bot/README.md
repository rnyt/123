# 🎓 Бот «Мои оценки» для колледжа

Telegram-бот для учащихся колледжа (ССО, Беларусь). Считает средний балл и отметку за семестр
**по Правилам аттестации ССО**, следит за ОКР, лабораторными, практическими и курсовыми,
показывает допуск к экзаменам и итог, а после сессии отправляет семестр в архив.
Напоминает внести оценки и защитить работы, но не спамит и молчит на каникулах.

```
🎓 2 курс · 1 семестр
🗓 До сессии 41 день (22.12–14.01)
📊 Средний балл: 8,93 ≈ 9
📚 6 предметов · 20 оценок
🔬 Зачтено работ: 1 из 3 ▰▱▱

🎓 Сессия: 1 экзамен, 1 диф. зачёт, 1 зачёт
🎫 Допуск есть: 0 из 3

❌ Не аттестован / нет допуска: 5 из 6
📌 Нет ОКР: Физика, ТОЭ, Охрана труда, История
⏳ Не зачтены работы: Высшая математика (ЛР 2, ЛР 3)
📐 Курсовой не защищён: ТОЭ
```

Карточка предмета:

```
📐 Высшая математика
🎓 В сессию: экзамен

📊 За семестр: 8 (7,75) · 5 оценок
🧮 (ОКР 8 + текущие 7,50) / 2 = 7,75
📝 7, 8, 6
📌 ОКР: 8 ✅
🔬 Лабораторные: зачтено 1 из 3 ▰▱▱ · оценки: 9
⏳ осталось: ЛР 3 · ❌ не зачтено: ЛР 2
🎓 Экзамен: ещё не сдан

❌ Нет допуска к экзамену: не зачтены ЛР 2, ЛР 3
```

## Запуск

### Самый простой (Windows / Linux / macOS)

1. Нужен Python 3.10–3.14 (на Windows — с python.org, галочка «Add to PATH»).
2. **Windows:** двойной клик по `start.bat`. **Linux/macOS:** `./start.sh`.
3. При первом запуске бот попросит токен (его выдаёт @BotFather) и сохранит его в `.env`.
4. Напиши боту `/start`. Владелец (по умолчанию @ztpst) сразу получает доступ и `/apanel`.

Бот работает, пока открыто окно. Чтобы он работал всегда, запусти его на сервере.

### Хостинг с панелью (fps.ms, Pterodactyl и похожие)

Бот занимает ~75 МБ памяти, поэтому влезает и в бесплатные тарифы со 128 МБ (fps.ms и т.п.).

1. Загрузи архив бота **в корень** сервера (вкладка Files) и нажми у него «⋯» → **Unarchive**.
   В корне должны оказаться `app.py`, `requirements.txt`, `.env` и папка `bot`. Сам архив потом можно удалить.
2. Если `.env` нет — создай его (Files → New File) со строкой `BOT_TOKEN=...`.
3. Вкладка **Startup**: Docker Image — Python **3.12** (подойдёт 3.10–3.14), App py file — `app.py`,
   Requirements file — `requirements.txt` (обычно это уже стоит по умолчанию).
4. Вкладка **Console** → **Start** (или Restart). Через полминуты в консоли будет
   `✅ Всё работает: открой t.me/… и нажми /start`.

Что значат сообщения в консоли:

| В консоли | Что делать |
|---|---|
| `[notice] A new release of pip is available` | Ничего, это не ошибка |
| `❌ Python 3.x не подходит` | Startup → Docker Image → Python 3.12, Restart |
| `⏳ Не нашёл библиотеку …` | Ничего: бот сам ставит библиотеки и перезапускается |
| `Не задан BOT_TOKEN` | Впиши токен в `.env` (Files → `.env`) |
| `Telegram не принял токен` | Токен неверный или отозван — возьми новый у @BotFather |
| `Не получается подключиться к Telegram` | Нет доступа к api.telegram.org — нужен `PROXY_URL` или другой хостинг |
| После `notice` ничего, сервер выключился | Не хватило памяти — нужна эта версия бота (с `bot/lowmem.py`) |

База с оценками — `data/grades.db` на сервере, её можно скачать там же в Files.
При обновлении бота папку `data` не удаляй.

### Docker (на сервере, 24/7)

```bash
cp .env.example .env    # впиши BOT_TOKEN
docker compose up -d --build
docker compose logs -f
```

### Вручную

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m bot
```

> 🔒 Токен — как пароль: он лежит только в `.env`, а `.env` не попадает в git.
> Если токен где-то засветился — в @BotFather: `/revoke` и новый токен в `.env`.

## Как пользоваться

| Пишешь в чат | Что произойдёт |
|---|---|
| `физ 8 9` | оценки 8 и 9 по физике |
| `физра 10910` | слитно: 10, 9, 10 (бот сам разделит) |
| `1078105` | 10, 7, 8, 10, 5 — и кнопками выбрать предмет |
| `физ окр 7` | оценка за ОКР |
| `тоэ 8` | по своему сокращению предмета |
| `физ` | открыть карточку предмета |
| несколько строк: `физра 10910` ⏎ `охрана 99910` ⏎ `физика 101010` | сразу в несколько предметов |

Сокращение задаётся в скобках при добавлении: `Теоретические основы электротехники (ТОЭ)`.
Задать или поменять его можно и потом: ⚙️ предмета → «🏷 Сокращение». Бот понимает и студенческие
сокращения вроде «матан», «вышка», «физра» и «оаип», а также опечатки.

**Предметы бывают разные.** Без экзамена и зачёта итог — просто отметка за семестр; без ОКР —
аттестация только по работам (и курсовому, если он есть). На шаге настройки есть кнопки
«▫️ Ни в одном нет» / «📌 Во всех есть» и «Сбросить: все без экзамена», а предметы, добавленные позже,
сразу открываются на этом же экране. Предмет без единой оценки помечается ▫️, а не ✅.

**Работы.** «🔬 + Лабораторная» / «🛠 + Практическая» (сразу несколько, номера бот ставит сам) →
«📂 Работы» → работа → «✅ Зачтено» / «❌ Не зачтено» / «⬅️ Назад». После «Зачтено» бот спросит
оценку («Без оценки», если поставили только зачёт). Оценка за работу идёт в средний.

**Экзамен / диф. зачёт / зачёт.** Форма выбирается при знакомстве или в ⚙️ предмета. В карточке
видно, есть ли допуск и какой выйдет итог при каждой отметке. При семестровой 9+ есть кнопка «🎉 Автомат».

**Сессия и архив.** Даты сессии и каникул вводятся текстом: `22.12–14.01` или `22 декабря – 14 января`.
Когда все экзамены сданы или сессия закончилась, бот спросит: «Отправить семестр в архив?» (да / позже /
не спрашивать). Архив открывается кнопкой «🗂 Архив» в меню: там итоги каждого семестра и средний за всё обучение.
Следующий семестр начинается сам: после 1-го — 2-й того же курса, после 2-го — 1-й следующего.

**Команды:** `/menu`, `/stats`, `/archive`, `/settings`, `/help` (все команды и правила),
`/apanel` (только владелец).

## Как считается (Правила аттестации ССО)

Постановление Минобразования РБ № 282 от 23.08.2022 (в ред. пост. № 42 от 18.02.2025):

| Правило | Что делает бот |
|---|---|
| п. 4 — положительные отметки от **3** | порог сдачи по умолчанию 3 (меняется в ⚙️ → 🔢) |
| п. 8 — математическое округление | 8,5 → 9, 8,4 → 8 |
| п. 12 — лабораторные: «зачтено/не зачтено», практические: отметки | у работы статус и необязательная оценка |
| п. 13 — неудовл. ОКР → новый вариант в течение 2 недель | подсказка о пересдаче, новая оценка заменяет старую |
| п. 15 — курсовой по 10-балльной, ниже 3 — новое задание | курсовой нужен для допуска |
| п. 19–20 — допуск: за семестр от 3, курсовой от 3, ЛР и ПР зачтены | «🎫 Допуск есть / нет — почему» |
| п. 20 — за семестр 9+ — можно освободить от экзамена | кнопка «🎉 Автомат» |
| п. 22 — за семестр = среднее из ОКР, курсового и среднего текущих | формула прямо в карточке |
| п. 23 — «не аттестован», если не сданы ОКР, работы, курсовой | «❌ Не аттестован: …» |
| п. 26 — задолженность закрыть до месяца после начала семестра | «🆘 Задолженность» с подсказкой |

**Где правила оставляют выбор (настраивается в ⚙️ → 🧮 «Как считать»):**
- *Итог с экзаменом.* По п. 20 отметка за экзамен окончательная. Во многих колледжах итог считают
  как среднее семестровой и экзаменационной отметок: 7 и 10 → 8,5 → **9**. По умолчанию стоит этот вариант,
  «только экзамен» можно включить.
- *Отметка за семестр.* По умолчанию — п. 22 (для предметов профессионального компонента).
  Для общеобразовательных предметов (простое среднее) есть переключатель в ⚙️ предмета, а для всех
  сразу — «Простое среднее».

## Админ-панель (`/apanel`)

Бот приватный: пользоваться может владелец и те, кого он пустил.
- **➕ Добавить по юзернейму:** `@ivan, @petr`. Человек напишет `/start` и сразу начнёт, данные у каждого свои.
- **📨 Заявки:** чужой человек нажимает «Попросить доступ», а владельцу приходит карточка «✅ Пустить / ❌ Отказать».
- **👥 Пользователи:** список и **тихий просмотр результатов** (пользователь не получает уведомлений), «🔒 Закрыть доступ».
- **🔓 Открыть для всех**, если бот нужен всей группе.

Владелец задаётся в `.env` (`OWNER=ztpst`). При первом входе бот запоминает его id: если кто-то потом
займёт этот юзернейм, админом он не станет.

## Настройки (`.env`)

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен от @BotFather (обязательно) | — |
| `OWNER` | Владелец: юзернейм или id | `ztpst` |
| `DEFAULT_TZ` | Часовой пояс новых пользователей | `Europe/Minsk` |
| `ALLOWED_USERS` | Доп. разрешённые id через запятую | пусто |
| `DB_PATH` | Путь к базе SQLite (это и резервная копия) | `data/grades.db` |
| `PROXY_URL` | Прокси до Telegram: `http://…` или `socks5://…` | пусто |
| `LOG_LEVEL` | `DEBUG` / `INFO` / `WARNING` | `INFO` |
| `LOW_MEMORY` | Экономия памяти (~75 МБ вместо ~170 МБ); `0` — выключить | `1` |
| `TELEGRAM_API_URL` | Свой Bot API сервер, например `http://localhost:8081` | пусто |

## Как бот улучшался

**Первая версия (20 шагов):** каркас на aiogram 3 и SQLite с миграциями, знакомство, главное меню,
карточка предмета, ввод оценок кнопками и текстом, ОКР, лабораторные и практические, правила аттестации,
быстрый ввод с сокращениями и опечатками, отмена, «сколько нужно до следующей оценки», умные напоминания,
часовой пояс, чистый чат, статистика, управление предметами, семестры, всё за день одним сообщением,
экспорт в Excel, очередь нажатий без гонок.

**Вторая версия — колледж (ССО):**
1. Изучены Правила аттестации ССО (пост. № 282, ред. 2025): порог 3, формула п. 22, допуск, автомат, задолженности.
2. Знакомство: курс (1–4) и семестр, предметы с сокращениями, вкладки ОКР / экзамены / курсовые, даты сессии и каникул.
3. Экзамен, диф. зачёт и зачёт: допуск, таблица «итог при отметке», итог `(семестр + экзамен) / 2` или только экзамен.
4. Курсовые проекты: отметка, влияние на семестр и допуск.
5. Работы: «зачтено / не зачтено» + оценка, которая идёт в средний.
6. Слитный ввод `1078105` → 10 7 8 10 5, несколько предметов по строкам.
7. Своё сокращение предмета (ТОЭ) — для ввода и кнопок.
8. Сессия в меню: «до сессии N дней», «идёт сессия», «каникулы».
9. После сессии и после всех экзаменов бот спрашивает «в архив?»; архив в меню, средний за всё обучение.
10. Переход к следующему семестру и курсу; перенос списка предметов или ввод новых.
11. Напоминания о незачтённых работах (отключаемо), тишина на каникулах.
12. Админ-панель `/apanel`: приглашения по юзернейму, заявки, тихий просмотр, закрытие доступа.
13. Владелец закрепляется по id; `/apanel` видна в меню команд только ему.
14. `/help` со всеми командами и правилами; `/archive`.
15. Проверка HTML каждого сообщения в тестах, как это делает Telegram.
16. Миграция базы v1 → v2 без потери данных; запуск одним файлом с вопросом про токен.
17. Хостинг со 128 МБ: aiogram собирает типы Telegram лениво (~75 МБ вместо ~170 МБ, запуск в 4 раза быстрее);
    `app.py` сам проверяет Python, доставляет библиотеки и объясняет ошибки по-русски.
    Проверено под жёстким лимитом 128 МБ на Python 3.10–3.14.

## Для разработчика

```
bot/
  __main__.py   запуск: python -m bot
  app.py        сборка диспетчера, обработка ошибок
  commands.py   меню команд и описание бота
  access.py     владелец, приглашения, открытый доступ
  config.py     настройки из окружения / .env (и вопрос про токен)
  lowmem.py     ленивая сборка типов aiogram — экономит ~90 МБ памяти
  db.py         SQLite и миграции
  repo.py       доступ к данным (всегда с проверкой владельца)
  logic.py      чистая логика: ввод, отметки по Правилам ССО, допуск, итог, напоминания
  dates.py      даты сессии и каникул
  screens.py    все экраны: текст + кнопки
  panel.py      «живая панель» — одно сообщение-меню
  reminders.py  напоминания и вопрос про архив
  export.py     CSV для Excel
  handlers/     старт и знакомство, меню, предметы и экзамены, работы, архив, настройки, админка, свободный текст
tests/
  harness.py    фейковый Telegram (с проверкой HTML, как у Telegram)
  test_logic.py, test_repo.py, test_flows.py, test_lowmem.py
```
